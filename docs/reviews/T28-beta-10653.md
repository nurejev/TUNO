# T28 MDE rollout — beta 10653

Date: 2026-09-30. T28 0.20. Promotion queue item 215.

## Why

Mihai ran a dry run from the policy bar on the new OIB Device Security policies, with **Add include · 🌊 Waves**. The plan added the waves, but it also removed `INT-SG-D-Win-Pilot`, `INT-SG-D-Win-Pre-Pilot`, `INT-SG-U-Win-Pilot` and `INT-SG-U-Win-Pre-Pilot` ("pilot: the waves take over"), and asked for a typed REMOVE.

His words:

- "add include, should only add include or there should be an option to also remove the others"
- "this on new policies when adding the waves"

Mockup: `t28-bar-add-only-mockup.html`. He picked **A: only add, with one tick for the pilot groups**.

## Cause

Since 10646, the bar's Waves target followed `cfg.pilotGroupsOff`. That is the 🧪 tick shown with ⚔️ and ⚡①, and it is on by default. So a bar dry run meant only to add also took the pilots off.

## What changed

- **A tick in the bar:** 🧪 also take the pilot groups off.
  - It shows with 🌊 Waves and Add include or Add exclude, and only when pilot groups are configured.
  - It is off by default and not saved.
  - Changing it drops a dry run it no longer matches.
- **Off (the default): the plan only adds.**
  - The plan is confirmed with a tick, with no REMOVE to type.
  - The pilot assignments that would have come off are named under "Left out, with the reason", with the tick to use: "🧪 N pilot assignments stay on (…): this plan only adds the waves. Tick … to take them off as well."
- **On:** the plan from before this build — pilots off where every wave of the policy's kind is in the new policy and out of the old one.
- **⚔️ and ⚡①** keep their own tick, unchanged.

## Validation

- **Tracked suites: all 17 pass.** `mderollout/screen`: 249 (+6). The pilot answer is fixed for the check, because where a pilot may come off is `pilotsFor`'s job and is tested above it. The checks:
  - the tick shows beside 🌊 Waves, off, while ⚔️'s own tick is on;
  - off: only include steps, no REMOVE, no pilot count in the title, and the pilot kept on is named with the tick;
  - on: the pilot comes off, typed REMOVE;
  - changing the tick drops the plan;
  - Remove has no tick;
  - back to Group, the tick goes.
- **Scratch suites:** unchanged against the baseline.
- **Real browser** (demo; 1440 light and dark, 390): the tick sits in the bar after the "each policy's kind" line. No page errors, and the page never scrolls sideways.
