# T28 MDE rollout — beta 10637

Date: 2026-09-29. T28 0.6. Promotion queue item 199.

## Change

Implements the selected option 2 report workspace. T28 now uses grouped navigation across the top (Policies, Conflicts, Waves & members, Reports, Changes, Settings). The existing policy, group, membership, plan, confirmation, backup, read-back and undo workflows remain available. The app-wide sidebar retains the user's chosen expanded/collapsed state.

Reports has a persistent three-report selector and one preview. A compact header replaces the large introduction; supporting tool information is expandable. Report exports are grouped in one menu; the existing overall rollout exports remain available on the operational panes.

The preview is built from the exact saved, escaped HTML export, not a newly evaluated live model. Configuration and conflicts now have inline evidence. Report sections, long exception lists and old-policy coverage fold independently; new-policy coverage starts expanded. Full policy names, group kinds, member counts, filters, exclusions, settings and uncertainty wording remain available. Wide tables scroll inside their own keyboard-focusable region.

Each report retains policy-read and generation timestamps. Configuration also shows the member-read timestamp and when owners were attempted. A newer policy/member snapshot, changed rules or session writes mark affected saved reports as needing regeneration. Missing policy surfaces and unavailable members remain explicit. A failed fresh conflict read retains the prior report and does not append a successful check.

No new permissions, report API endpoints or tenant writes were introduced. Existing export generators and payloads are unchanged. Bundled PowerShell changes are build stamps only.
