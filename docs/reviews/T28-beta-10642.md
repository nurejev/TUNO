## 🕳 Left out (`MdeMembers.leftOutOf`, `leftOutCsv`)

The members read now reads Intune's devices on **every platform, once**. Windows remains the subset the waves use; the other platforms say what a user with no Windows device does have.

| List | Who | Scope |
| --- | --- | --- |
| Users with no Windows device | Users of a country group in the table with no Windows device by Intune primary user. They get the user wave only. Shown with their other devices in Intune (macOS 1 · iOS 1…, or "nothing in Intune"). | per wave, narrowed by country chip |
| Primary user in no country group | Windows devices whose primary user is in no country group of the table | tenant |
| No primary user | Windows devices with no primary user | tenant |
| No Entra object | A country's devices that cannot be group members | per wave |
| Excluded | A country's devices in the device exclusion group (kept on the old set) | per wave |

**Screen** (layout A):

- A **🕳 Left out · N** chip in the 👥 toolbar. Clicking it again goes back to the countries.
- Tiles per reason narrow the device list.
- Chips per country narrow the users.
- A row's **"N users have none"** and the header's **no-primary-user count** link straight to the view.
- The lists show the first 300 rows; the CSV (`Kind, Region, Country, User, Device, Why, Other devices, Last sync`) has everyone.

## Left out by default: 78 policies, ➕ include

- **The default list.** `DEFAULTS.leaveOut` holds the 78 names. Matching is by folded name (dashes, spaces, underscores, case). They show under 🚫 as ➖ left out by name, each with a **➕ include** button.
  - ➕ include removes the name from this tenant's list. The pair's groups get their kinds read (a scope change used not to trigger that read, so the twin proposals were missing).
  - The 🚫 intro names the Leave-out list.
- **Migration** (`leaveOutSeed: 10642`):
  - A config saved at 10639 or 10640 has an explicit, empty `leaveOut`. It gets the defaults merged in **once**.
  - From then on, what was included stays included.
  - ⚙️ Save carries the seed.
- **The demo.** The demo's one-rule ASR policy is on the list, so it now starts out of scope. The screen suite includes it back with ➕ before the rest of its checks, which exercises the button. The engine suite takes it off the list in its own config.
