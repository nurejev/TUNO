# T28 MDE rollout — beta 10652

Date: 2026-09-30. T28 0.19. Promotion queue item 214.

## Why

Mihai: "add the to be include", with five policy names:

- Win - OIB - SC - Device Security - U - Windows Sandbox - v3.4
- Win - OIB - SC - Device Security - D - Config Refresh - v3.2
- Win - OIB - SC - Device Security - D - User Rights - v3.7
- Win - OIB - SC - Device Security - U - Windows Spotlight and Org Messages - v3.0
- Win - OIB - SC - Device Security - D - Windows Package Manager - v3.5

This is not a layout change, so there was no mockup.

## What changed

**The default ⚙️ Also-in list** (`DEFAULTS.alsoInScope`) has these five after the five from 10634, ten names in all. A policy on this list:

- is in scope and new although nothing in it is an MDE area;
- pulls in an old policy that sets one of its settings, to be compared with it in ⚔️.

**A tenant that saved its rules before this build.** Its config carries its own Also-in list, so a new default would never reach it. As with the Leave-out list (10642), there is a seed:

- `alsoInScopeSeed` is 10652.
- A config saved without that seed gets the new default names merged in **once**. A name already there under other dashes or case is not added twice.
- A name taken off by hand after that stays off. The rules save keeps the seed.
- PVM's config gets the five on its next load.

**Their settings count as 🔒 Device security**, like their OIB siblings. `catOfKey` now knows:

- `windowssandbox`
- `_configrefresh_`
- `desktopappinstaller`
- `windowsspotlight`
- `organizationalmessages`

User Rights (`userrights`) already counted. Device security is not an MDE area, so this changes only how these policies are grouped. No other policy comes into scope because of it.

**Bookkeeping fixed:** 10651 put its 0.18 note in `TOOL_VERSIONS` but left the number at 0.17. It is now 0.19.

## Validation

- **Tracked suites: all 17 pass.** `mderollout/engine`: 195 (+3):
  - ten names by default, the Spotlight one among them;
  - a config saved before 10652 gets the five once, keeps its own name, and doesn't double one written in capitals;
  - a name taken off afterwards stays off;
  - the Sandbox, Config Refresh, Package Manager, Spotlight, organisational messages and User Rights settings are Device security.
- **Scratch suites:** unchanged against the baseline.
