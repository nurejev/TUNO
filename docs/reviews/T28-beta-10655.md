## What changed

**The read** (`MdeMembers.readInput`). Every Windows device that Intune names no primary user for, and that has an Entra object, gets one more read:

- `GET /devices/{id}/registeredOwners/microsoft.graph.user?$select=id,userPrincipalName,usageLocation`, six at a time.
- Learn describes the registered owner as "The user that cloud joined the device or registered their personal device". That's what a user's Devices list in Entra shows.
- A failed owner read is said in the read's notes, and that device falls back to its name.
- The members read now also asks for `User.Read.All`, for the owners' usage location. The app registration already declares it for ⊘, so no new scope comes in.

**Placing a device** (`compute`), in this order:

| # | Rule | Said as |
| --- | --- | --- |
| 1 | The Intune primary user's country group(s) | as before |
| 2 | The Entra owner's country group(s). The device joins the owner exactly as a primary user's would, so it also sits in a pilot group of theirs. | "none · by Entra owner x" |
| 3 | The owner is in no country group: their usage location (ISO2) is a country row's suffix | "by x's usage location" |
| 4 | The first three letters of the name are a country row's ISO3, whether a dash follows or not (NLD-…, IND5CD…) | "by name IND" |
| — | none of these | 🕳 left out, as before |

**Limits of the name rule:**

- Only a code of a country in the table counts, and only one with a plain three-letter device group.
- Poland's city groups (POL-WAW, POL-SKARB) take nothing by name, because a name can't pick the city.
- A pilot group never takes a device by location or name.
- A name like CANON… would read as Canada (CAN), because the letters after the code aren't checked. Devices with a primary user or owner are never affected by this. Mihai's serials follow the code directly (IND**5CD**…), so a separator can't be required.

**A primary user always wins.** A device named for another country says "the name says Germany" in the country detail and in the CSV. It is counted per country ("N named for another country — the user decides"), not moved.

**🕳 Left out:**

- An owner who got a device through rule 2 is no longer a "user with no Windows device".
- The no-primary-user tile, and the header count, only cover what none of the rules placed.
- The header says how a country is found, and how many devices were placed that way.

**CSV:** a new last column, "Country by". The Primary user column is left empty for a device placed any other way.

**Demo:** a `registeredOwners` route, reading a device's `_owner`.
