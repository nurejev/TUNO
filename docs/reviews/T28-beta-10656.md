## What changed

**A pilot knows its country** (`compute`):

- A pilot row gets `parentKey` and `parentCountry`: the non-pilot row whose user group its own name extends (`…-NL-Breda` → `…-NL`).
- It also gets `migrated` (from `cfg.members.migrated`) and `outsideParent`: its users that the country doesn't hold.

**The country's go-live migrates the pilot** (`planOps`). For each country in the plan whose user group is nested, or is nested by this plan, each batched pilot inside it that isn't migrated yet gets these steps after the country's own:

1. **Remove** the pilot's users that were put in the user wave directly. `needsOk` is the country's user-group nest, when that nest is in this plan.
2. **Unnest** the pilot's user group from the user wave, if 🧪 Finish had nested it. Same `needsOk`.
3. **Unnest** the pilot's device group from the device wave. This happens only when the country's device group is in the device wave, now or in this plan, with `needsOk` on its add and nest. Otherwise the step is skipped with the reason.

The plan also says what the migration means:

- It warns how many pilot users aren't in a batch yet and come in with the country at once.
- REMOVE is typed.
- `plan.migrate` names the migration.

**Not migrated when a pilot user is outside the country.** Those users would leave the wave. The plan skips the migration and names the users, and the panel says "Not migratable into Netherlands: …".

**After the run** (`applyMem`):

- The pilot is listed as migrated only once every one of its migration steps has read back clean. It then leaves `batched`, joins `migrated`, and is never planned again.
- Its device group is left in place, out of the wave.
- 📜 undo reverses the steps. Once they have all read back clean, the pilot is back in its batches.

**On the screen:**

- The country row reads "🧪 going live migrates NL Breda".
- The pilot's batch panel has **🧪 Migrate to the wave with Netherlands →**. It plans the country's go-live with every step on, plus the migration, and the plan opens under the panel. When NL is already live, that is the migration alone.
- A migrated pilot row reads "🧪 migrated into Netherlands" and can't be ticked. Its panel says what that means.
